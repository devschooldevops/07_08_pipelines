# Lesson plan

## General information

**Duration**: 3 hours (1h theory, 2h practic)

**Primary teacher**: Mihai Budurescu

**Secondary teacher** (if needed): -

## Goal
At the end of the lesson, the students should:
- understand pipelines architecture and the differences between stages/jobs/tasks in Azure DevOps pipelines
- have an understand of an "agent"
- be able to create a simple pipeline in Azure DevOps and discover the tasks with tasks assistant
- explore different types of pipelines depending on their purpose, platform and programming language
- deploy an application using multistage pipeline
- know how to explore DevOps careers and learning paths

## Resources required/used
Example:
- Azure Devops Organization with parallelism grant requested to Microsoft
- Azure Subscription 
- Azure App Services

## Prerequisites
- Azure Devops Organization
- Azure Student subcription
- Basic Git commands knowledge
